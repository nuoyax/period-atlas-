# 周期图谱 · 生活里的周期

**中文** · [English](README.md)

把生活中各种**周期性现象**画成一组会动的曲线：从一天里的褪黑素、体温、通勤高峰，到一月里的月相与潮汐，再到一年里的太阳高度角、农事节气、赛场赛季，一直走到数年的闰年与太阳活动周。

外加一张 **太阳系 3D 视图**：八颗行星按各自的**真实恒星周期**绕太阳运行，点开还有天体的参数预览面板。

技术栈：React 18 + TypeScript + Vite 5 + three.js。零外部资源、不走 CDN、运行时不发任何网络请求。

## 跑起来

```bash
npm install
npm run dev        # 开发服务器
npm run build      # tsc -b && vite build → 多文件 dist/
npm run preview    # 用 HTTP 打开 dist/（不要用 file:// 直接开 dist/index.html）
npm run check:data # 数据层奇偶/不变量检查
```

`npm run build` 出的是标准多文件 `dist/`：资源路径是绝对的，所以必须走 HTTP。直接双击 `dist/index.html` 会白屏。

## 怎么用

- **行业下拉框**：14 个行业——生活日常 / 农业 / 植物科类 / 太空航天 / 海洋渔业 / 医疗健康 / 能源电力 / 交通物流 / 金融零售 / 制造业 / 教育 / 旅游 / 体育建筑 / 传媒内容。选谁只看谁；选「全部行业」则全部同屏。
- **尺度按钮**：时间尺度分五层——一天（24 小时）、一周（7 天）、一月（28–31 天）、一年（365.25 天）、数年（4 年）。开关哪一层，只影响可见性。
- 两级筛选互不干扰。被隐藏的曲线时间**冻结**，重新显示时不会「跳过」那段时间。
- **播放 / 暂停**、**速度**（慢 / 常速 / 快：一天对应 48 / 16 / 8 秒）、**时刻滑块**（作用于 24 小时这一层）。
- **波形 / 相位轮**：相位轮把「一天」这一层的所有曲线叠在同一个 24 小时圆盘上，同一钟点落在同一条半径。
- **太阳系 3D**：拖动旋转视角、滚轮缩放、点行星或名称聚焦；倍率可调（1 天/秒 … 10 年/秒）；预览面板给出该天体的真实参数。
- **表格视图**：全部现象的无障碍等价表格（尺度、周期、活跃窗口、峰值、当前数值、生活里的例子）。
- **深色模式**：右上角切换。深色不是自动反色，而是从同一族色阶里**另选**一组经过校验的色。

## 每张图一条自己的纵轴

曲线形状统一画在 0–1 的相对高度上，但**显示时按各自真实的物理量与量程换算**：

| 现象 | 纵轴 |
|---|---|
| 月相 | 月面照亮比例 % |
| 潮汐 | 潮位 m |
| 血压晨峰 | 收缩压 mmHg |
| 核心体温 | ℃ |
| 火箭发动机点火 | 推力 % 额定 |
| 贮箱加注 / 液氧蒸发 | 贮箱液位 % |
| 气孔开闭 | 气孔导度 mmol/(m²·s) |
| 物候期 | 叶面积指数 LAI |

所以这是一组**小图**：横轴各画各的周期，纵轴各用各的量纲，**只能纵向读单张图的峰谷，不能横向比两张图的高低**。本身没有单一物理量的（通勤高峰、收视指数等），就如实标成「指数」。

## 颜色为什么是色阶而不是分类色

14 个行业、数十条曲线，远超一张分类色板 8 个槽的能力上限——硬塞第 9 个色会在色觉缺陷下与已有色无法区分。所以：

- **颜色表示时间尺度**（序数色阶）：同一族蓝色由浅到深，五个层级各一档，另配全称与区间文字，识别不靠颜色单独承担。
- **颜色跟着实体走，不跟筛选走**：切换行业不会给幸存曲线重新上色，只是显隐。
- 分类色板 7 槽、序数色阶 5 档，亮/暗两种模式均通过 `validate_palette.js` 的对比度、色度下限、色觉缺陷相邻色距与正常视觉色距检查（结果由脚本判定，非肉眼估计）。

## 3D 视图里的比例诚实

真实比例不可用——海王星 30 AU（45 亿 km）在外，地球半径 6371 km 在内，差 4 个数量级。所以场景**距离按平方根、大小按 0.4 次幂压缩**，并在页面上如实写明：

> 距离按平方根、大小按 0.4 次幂压缩显示，非真实比例

预览面板里的半径与半长轴是**真实值**，只有画面上的几何是压缩后的。行星位置用真实恒星周期与 J2000 平黄经驱动，并注明是**平黄经**——没有计偏心率与摄动。渲染端固定 `PointLight.decay = 0`：three r155 起是物理正确光照，若按真实距离衰减，海王星只收到地球的约 1/900，会变成一颗纯黑的球。

3D 视图有**自己的天数**，初值取 2D 的钟，之后按自己的倍率推进；两边只通过「同步回 2D」单向交接一次，2D 的时间轴不会被 3D 拖着跑。

## 工程结构

```
src/
├─ main.tsx / App.tsx        顶层结构、视图切换
├─ data/                     series.ts（79 条）· yax.ts · phases.ts · levels.ts · industries.ts · astro.ts
├─ model/                    math · shape · rhythm · axis · readout · bestday · clock · theme
├─ components/               Controls · BandBar · WaveView · WaveCard · RingView · TableView · FootNote
│  └─ orbit/                 OrbitView · scene.ts · bodies.ts · textures.ts · rates.ts · MiniOrbit · BodyPreview
└─ styles/tokens.css
```

有一个决定撑着整套东西：**React 负责「有什么」，命令式 DOM 负责「动起来」。** 79 张 SVG 卡片由**一个**模块级时钟和**一条** rAF 循环以 60fps 驱动，订阅者直接写 `setAttribute` / `textContent`；`useState` 只承载**结构性**变化（行业、可见尺度、视图、表格、播放、速度），每张卡片 `memo` 过，动画期间永不 re-render。若改由 `setState` 驱动，每帧要 diff 79 棵子树，必然卡死。

## 数据源

`src/data/series.ts` 里 79 条现象（尺度、周期、活跃窗口、峰值、形状函数），配套量程表在 `src/data/yax.ts`。改数据只需改这两处，其余（轴、图例、表格、悬停、相位轮）自动跟随。`npm run check:data` 校验条数、尺度分布、行业分布、没有曲线落回默认量程，以及被筛掉的曲线其相位查询返回 `null`。

## 目录名说明

仓库目录当前叫 `cycle-animation`，`package.json` 的 `name` 是 `period-atlas`——两者不一致是历史遗留：改名时本机的工作目录正锁在它上面，`mv` 报「文件正在使用中」。**不影响任何运行**，构建、预览、测试都与目录名无关。
